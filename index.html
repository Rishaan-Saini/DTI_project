    About This Project

    This project is a simple second-hand marketplace designed especially for students to buy and sell used items easily. Many useful items often go unused, and this platform helps give them a second life. The idea behind this project is to create a space where people can list items they no longer need and others can find them at affordable prices. It also promotes reuse and reduces unnecessary waste.

    Users can browse available items, add their own listings, and connect with others in a simple and user-friendly way. This project was developed as part of a learning experience to understand web development and build a practical solution for everyday problems.
